# ULA Monitor · Técnico en terreno (mockups)

Repositorio **temporal** para revisar con el equipo los mockups de la app móvil del curso Tecnologías Web y Móviles.

- Es la versión web de la app (React Native + Expo) con **datos falsos**: no se conecta al backend.
- Contiene solo el sitio ya compilado; el código fuente vive en el proyecto del equipo.
- En el navegador del computador se ve como un teléfono centrado. En el celular se abre a pantalla completa.
- El *pull to refresh* solo funciona en el teléfono con Expo Go, no en esta versión web.

Credenciales de prueba: aparecen en la pantalla de inicio de sesión (botón **Usar**).
